# OrangeHRM Manual QA Testing Project

## 📌 Project Overview

This project demonstrates manual QA testing of the OrangeHRM web application.

The goal of the project was to verify the functionality of the application, identify defects, and document test scenarios and execution results using structured test cases.

## 🧪 Testing Scope

The testing covered key areas of the OrangeHRM application, including:

* Login and authentication
* Dashboard
* Employee Management (PIM)
* Employee List
* Adding employees
* Editing employee information
* Viewing employee profiles
* Deleting employees
* Validation messages
* Session expiration
* Data persistence and search

## 📋 Test Cases

The project contains **42 manual test cases** covering positive, negative, validation, and functional scenarios.

Each test case includes relevant information such as:

* Test Case ID
* Test Scenario
* Preconditions
* Test Steps
* Test Data
* Expected Result
* Actual Result
* Status
* Priority

## 🐞 Defect Identification

During test execution, several application behaviors were identified and documented as potential defects.

Examples include:

* Session expiration behavior
* Employee information update behavior
* Employee ID validation
* Loading behavior after navigating back from an employee profile
* Validation and error-message behavior

## 🛠️ Tools Used

* **OrangeHRM** – Application under test
* **Google Sheets / Markdown** – Test case documentation
* **GitHub** – Project documentation and version control

## 📊 Testing Approach

The testing process included:

1. Reviewing application requirements and functionality
2. Designing manual test cases
3. Preparing test data
4. Executing test scenarios
5. Recording actual results
6. Comparing actual results with expected results
7. Identifying and documenting defects
8. Reviewing and updating test cases
